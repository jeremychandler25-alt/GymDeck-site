# GymDeck-site

Public privacy policy and support pages for GymDeck.

- Privacy policy: [privacy/index.html](privacy/index.html)
- Support: [support/index.html](support/index.html)

GitHub Pages is set up with the official static-site workflow in `.github/workflows/pages.yml`. Publishing uses this repository only. The Pages site root is this repository, so the public paths are `/GymDeck-site/`, `/GymDeck-site/privacy/`, and `/GymDeck-site/support/`.
